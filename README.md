# Admin Analytics

A modular, configurable business administration platform with a reusable core and separate business domain modules.

## Status

Repository bootstrap. Application implementation has not started. The app name is a working title.

## Planned stack

- Backend: Python, FastAPI and Pydantic.
- Database: PostgreSQL, SQLAlchemy and Alembic.
- Web: React, TypeScript and Vite.
- Configuration: JSON with a versioned schema and semantic validation.
- Local runtime: Docker Compose with Nginx routing.
- CI and testing: GitHub Actions, pytest and Playwright.

Business-specific terminology, pricing and policies belong in configuration or domain modules. Native mobile, AI integrations and public websites are deferred.

Setup instructions and supported versions will be added with the relevant implementation increments.
